# Agent instructions

- Read README.md, CONTRIBUTING.md, and the assigned issue before editing.
- Complete one issue per pull request with minimal, focused changes. Do not implement other backlog items.
- Keep all website text in English. Preserve accessibility, responsive layout, and the GitHub Pages base path.
- Never commit credentials, tokens, personal data, local environment files, node_modules, or dist.
- Do not introduce external services, dependencies, workflow permissions, or repository-setting changes unless the issue requires them.
- Add meaningful coverage for changed behavior. Validate with `npm test` and `npm run build`; avoid repeated unrelated checks. Capture the affected UI when practical.
- Report what changed and what was verified. Do not merge your own pull request.
